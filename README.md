## Что умеет

⏰ **Считает дни за вас.** «Когда была последняя прививка?» — больше не вопрос:
у каждого пункта ухода свой интервал, а кнопка «Сделано» пересчитывает «следующий
раз» от фактической даты выполнения. Смена интервала ничего не ломает — расписание
выводится из истории, а не хранится отдельной строкой.

📅 **Напоминания живут в вашем календаре.** Любой пункт ухода выгружается в
системный календарь файлом `.ics` — повторяющимся событием с будильником за
сутки. Дальше календарь справляется сам: без сервера, разрешений и push-подписок.
Разовый визит к ветеринару выгружается так же — одиночным событием на нужную дату.

📈 **Вес — вся история в одном графике.** Замеры хранятся с точностью до грамма,
график строится за всё время с автоподбором масштаба; тап по точке показывает
дату и значение. Заметили, что линия пошла вниз, — раньше, чем это станет проблемой.

🍽 **Корм: что подошло и сколько ушло.** Журнал покупок с вердиктом «подошёл /
не подошёл» и заметкой — чтобы не купить снова то, от чего было расстройство.
Расходы — столбиками по месяцам за полгода: бюджет на корм становится предсказуемым.

🔐 **Данные принадлежат вам.** Ни одного сетевого запроса: всё хранится локально
в браузере, приложение полностью работает офлайн. Бэкап и перенос на другое
устройство — JSON-файлом в одну кнопку из настроек.

🌗 **Приятно с телефона.** Интерфейс свёрстан мобильным-first от 360px, одной
рукой; тёмная тема подхватывается автоматически, фото питомца сжимается прямо
в браузере, чтобы не раздувать хранилище.

## Попробовать

Самый быстрый способ — [живое демо](https://l2cri.github.io/pet-care-tracker/):
откройте **Настройки → Загрузить демо-набор** — и в приложении появятся кот
Персик и пёс Бублик с готовой историей ухода, веса и корма. Все скриншоты выше
сняты именно с этого набора.

Если удобнее локально:

```bash
npm install
npm run dev
```

## Как это устроено

Чистый фронтенд на React + TypeScript + Vite: без бэкенда, UI-библиотек, роутера
и чартовых библиотек — графики нарисованы руками на SVG, а `.ics` собирает чистый
строковый генератор по RFC 5545. Каждое инженерное решение зафиксировано в ADR,
доменное ядро закрыто 217 автотестами.

Подробный разбор — в [about.md](about.md): инженерные решения, архитектура,
тесты и процесс разработки. Также [спека](docs/SPEC.md),
[архитектура](docs/ARCHITECTURE.md) и [глоссарий](docs/GLOSSARY.md).
