# Питомцы и дом (pet-care-tracker)

Личный трекер ухода за питомцами: прививки, обработка от паразитов, график веса, журнал корма. Чистый фронтенд без бэкенда — данные живут в браузере, напоминания экспортируются в системный календарь телефона через `.ics`.

Проект строится как **личный инструмент, заодно годный для портфолио**: реальная боль, живые данные, честный кейс.

**Статус:** спроектирован, код пишется по тикетам.

## Стек

React + TypeScript + Vite. Без UI-библиотек, без чартовых библиотек, без роутера. Графики — самописный SVG. Тесты — Vitest на чистое доменное ядро. Репозиторий и CI — GitLab, деплой — GitLab Pages.

## Разработка

Один тикет = одна сессия ZCode = отдельный git worktree = ветка `t/NN-slog`. Готовый
тикет проходит ревью-сессию `code-review` и уходит MR-ом в GitLab; **сливает в master
человек — кнопкой Merge со включённым squash** (один коммит на тикет). Подробности —
в [docs/WORKFLOW.md](docs/WORKFLOW.md).

## Дорожная карта

- **MVP (сейчас):** питомцы — пункты ухода с интервалами, таймеры и срочность, история выполнений, .ics-экспорт, вес + график, журнал корма, JSON-бэкап, демо-набор.
- **Итерация 2:** домашние дела (фильтры для воды, полив растений) — на той же универсальной модели «подопечный», без миграции данных.
