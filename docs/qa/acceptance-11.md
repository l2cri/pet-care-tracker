### б) Экспорт .ics

- **Валидный VCALENDAR с RRULE нужной частоты:** `src/domain/ics.test.ts`, блок «эталонные VCALENDAR по единицам интервала» — полные эталонные строки (CRLF, финальный CRLF по RFC 5545 §3.4) для days/weeks/months/years → FREQ=DAILY/WEEKLY/MONTHLY/YEARLY c INTERVAL; отдельный тест «INTERVAL=1 опускается».
- **VALARM за сутки:** эталон `referenceVcalendar` каждого теста содержит `BEGIN:VALARM` / `TRIGGER:-P1D` / `ACTION:DISPLAY` — будильник за сутки закреплён во всех эталонах.
- **DTSTART = следующий раз:** `src/app/icsDownload.test.ts`, блок «calendarStart»: непустой журнал — вычисленный nextDue, пустой журнал — сегодня; плюс «downloadCareItemCalendar… VCALENDAR из ядра» и «пустой журнал — DTSTART сегодня». Дополнительные гарантии: экранирование и folding — `ics.test.ts` §3.3.11/§3.1.

### в) Бэкап round-trip

- **Выгрузил JSON:** `src/storage/backup.test.ts` «экспорт — конверт { formatVersion, state } текущей версии»; скачивание — `src/app/backupDownload.test.ts`.
- **Стёр всё:** `src/app/store.test.tsx` «replaceState(emptyAppState()) даёт состояние первого запуска», «автосейв сохранил замену»; `src/storage/localStorageRepo.test.ts` «wipe стирает ключ».
- **Загрузил → восстановилось один в один, включая фото:** `backup.test.ts` «экспорт → импорт восстанавливает состояние без потерь» — фикстура `testState.ts` содержит питомца с `photo: 'data:image/png;base64,…'` и записи с заметками (комментарий фикстуры: «именно их легче всего потерять при сериализации»); туда же «демо-набор проходит round-trip» и «пустое состояние проходит round-trip»; сквозное сохранение — `localStorageRepo.test.ts` «save → load без потерь».
