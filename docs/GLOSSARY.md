# Глоссарий

Единый словарь проекта: термин интерфейса (русский) ↔ кодовое имя (английский) ↔ определение. Использовать эти слова в коде, UI, тестах и обсуждениях; новый термин сначала попадает сюда.

| Термин | Код | Определение |
|---|---|---|
| **Подопечный** | `CareSubject` | Тот, о ком заботимся. Тип: `pet` (питомец), `item` (предмет ухода, например фильтр — итерация 2), `plant` (растение — итерация 2). Есть имя, вид, дата рождения, фото. В MVP интерфейс показывает только питомцев. |
| **Пункт ухода** | `CareItem` | Повторяющаяся забота, привязанная к подопечному: заголовок + интервал `{value, unit}`. Пример: «Прививка», каждые 12 месяцев. |
| **Интервал** | `Interval` | Пара «число + единица»: `days` / `weeks` / `months` / `years`. Единица определяет и арифметику следующей даты, и `FREQ` в RRULE. |
| **Запись выполнения** | `CompletionLogEntry` | Факт «сделано» с датой и опциональной заметкой (название вакцины, клиника). Единственное место, где хранится прошлое пункта ухода. |
| **Последний раз** | `lastDone` | Вычисляемое поле: дата последней записи выполнения. Нигде не хранится. |
| **Следующий раз** | `nextDue` | Вычисляемое поле: `lastDone + интервал`. Основа таймеров и срочности. Нигде не хранится. |
| **Разовое событие** | `OneOffEvent` | Событие без повтора: визит к ветеринару, стрижка к определённой дате. Флаг `done`. |
| **Замер веса** | `WeightEntry` | Дата + вес в **целых граммах** (в UI — килограммы). Целое число — чтобы не копить float-погрешности. |
| **Запись корма** | `FeedEntry` | Строка журнала корма: дата, название, цена, вердикт, заметка. |
| **Вердикт корма** | `verdict` | `'ok'` — подошёл, `'bad'` — не подошёл. Одна отметка, без рейтингов и шкал в MVP. |
| **Срочность** | `Urgency` | Классификация пункта по `nextDue`: `overdue` (дата прошла) — красный; `soon` (≤ 7 дней) — жёлтый; `calm` — серый. |
| **Окно «скоро»** | `SOON_WINDOW_DAYS` | 7 дней. Константа домена, границы покрыты тестами (6/7/8 дней). |
| **Таймер** | — | UI-отображение «через N дней» / «просрочено на N дней» для пункта ухода. |
| **Бейдж карточки** | — | Самый срочный пункт подопечного, вынесенный на его карточку на дашборде. |
| **Экспорт .ics** | — | Генерация календарного файла в браузере: all-day VEVENT + RRULE + VALARM за сутки; для разовых — одиночное событие. Канал напоминаний вместо push. |
| **Бэкап** | `backup` | JSON-файл со всем состоянием и полем `formatVersion`. Экспорт и импорт — кнопками в настройках. |
| **Демо-набор** | `demoData` | Два питомца с историей веса, корма и выполнений для скриншотов и демонстрации. Загружается и стирается кнопками в настройках. |
| **Дашборд** | `Dashboard` | Первый экран: карточки подопечных с бейджами + общий список дел «просрочено/скоро». |
| **Карточка питомца** | `PetCard` | Второй экран: вкладки Уход / Вес / Корм. |
| **Bottom-sheet** | `BottomSheet` | Модальная панель снизу: все формы добавления и редактирования. |
