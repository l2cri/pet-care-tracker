# ADR-0005: Самописные SVG-графики без библиотек

**Статус:** Принято (2026-10-24)

## Контекст

Нужны ровно два графика: линия веса за всю историю и столбики расходов на корм по месяцам. Чартовые библиотеки (Chart.js, uPlot и т.п.) тянут bundle, стили и API под сотни вариантов, которых в проекте не будет. С другой стороны, «нарисовал график с нуля и посчитал геометрию» — именно тот навык, который проект хочет показать в портфолио.

## Решение

Никаких чартовых библиотек. `domain` содержит чистую нормализацию данных → геометрия (автоскейл по min/max, защитные поля, вырожденные случаи: пусто, одна точка, все значения равны). React-компоненты только рендерят готовый SVG (линия с точками, столбики с подписями) и ловят тап по точке для тултипа. Линия веса — вся история; столбики расходов — последние 6 месяцев.

## Последствия

- (+) Нулевые зависимости для графиков; bundle остаётся минимальным.
- (+) Полный контроль над мобильным видом (тултип по тапу, а не ховер) и тёмной темой через токены.
- (+) Чистая нормализация тестируется юнит-тестами наравне с остальным ядром.
- (−) Оси, масштаб и адаптив — наше время и наша ответственность; компенсируется узостью задачи (два графика, без зума/легенд/анимаций).
- (−) Появится третий тип графика с легендой и зумом — пересмотреть решение, не наращивать самописность до «своей Chart.js».
