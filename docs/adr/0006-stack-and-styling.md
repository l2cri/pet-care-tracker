# ADR-0006: Стек и стили — React + TS + Vite, CSS Modules + токены, без роутера

**Статус:** Принято (2026-10-24)

## Контекст

Нужно выбрать фундамент для проекта на 2–3 недели вечеров, который одновременно читается работодателем и не тянет лишнего. Экранов всего два, фичи — CRUD + вычисления, вся ценность — в доменном ядре. Вкусовая часть (Tailwind vs ручной CSS, роутер vs стейт) определяет, что проект говорит о своём авторе.

## Решение

- **React + TypeScript + Vite** — рыночный стандарт, максимальная читаемость для ревьюера.
- **CSS Modules + дизайн-токены** (палитра, радиусы, отступы в CSS-переменных, файл `tokens.css`); тёмная тема через `prefers-color-scheme` без переключателя в MVP. Ни UI-библиотек, ни Tailwind: продолжение истории «минимум зависимостей, всё сам».
- **Без react-router**: два экрана (Дашборд, Карточка питомца) с навигацией стейтом; всё добавление-редактирование — через bottom-sheet модалки.

## Последствия

- (+) Зависимости почти исчерпываются React и Vite — bundle маленький, «зачем это здесь» не возникает.
- (+) Ручной CSS с токенами + тёмная тема дёшево показывают систему, а не набор классов.
- (−) Роутинга нет — глубокой ссылки на карточку питомца не будет; для личного инструмента несущественно, осознанно принято.
- (−) Если интерфейс вырастет за ~4 экрана или понадобится шаринг ссылок — вернуться к вопросу роутера отдельным ADR.
