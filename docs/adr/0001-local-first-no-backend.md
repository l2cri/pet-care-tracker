# ADR-0001: Local-first без бэкенда

**Статус:** Принято (2026-10-24)

## Контекст

Проект — личный инструмент на 2–3 недели вечеров, который должен заодно показывать инженерную культуру в портфолио. Бэкенд добавляет хостинг, API, аккаунты и время, а реальная потребность — «считать дни за меня и не терять прошлое» на одном телефоне. При этом браузерные данные хрупки: localStorage может быть очищен.

## Решение

Чистый фронтенд без бэкенда. Всё состояние — в localStorage за интерфейсом репозитория (точка замены на IndexedDB без касания ядра). Обязательный экспорт/импорт JSON-файла с полем `formatVersion` — кнопкой в настройках, как часть MVP, а не «потом». Фото — downscale через canvas до ~512px и хранение как dataURL, чтобы влезать в лимиты localStorage.

## Последствия

- (+) Нулевая стоимость эксплуатации, работа офлайн, приватность по построению (данные не покидают устройство).
- (+) Деплой — статикой на GitHub Pages.
- (+) Для портфолио честная история: «понял цену локальных данных — сделал бэкап обязательной фичей».
- (−) Ответственность за сохранность на пользователе; в README и UI явно проговариваем бэкап.
- (−) Синхронизация между устройствами — только ручным переносом JSON-файла.
