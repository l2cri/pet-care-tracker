# 04: Стор, дашборд и подопечные

**What to build:** Первый живой экран: дашборд с карточками подопечных. Кнопка «+» открывает bottom-sheet — имя, вид, дата рождения, фото (сжимается на клиенте до ~512px). При создании питомца ему автоматически создаётся редактируемый пресет-набор пунктов ухода. Всё сохраняется между сессиями.

**Blocked by:** 03 (Хранилище и JSON-бэкап).

**Status:** ready-for-agent

- [ ] Стор на context + useReducer; каждое изменение автоматически сохраняется через репозиторий
- [ ] Дашборд показывает карточки подопечных: фото, имя, вид
- [ ] Добавление подопечного через bottom-sheet; фото с телефона сжимается через canvas до dataURL ~512px
- [ ] Редактирование подопечного (имя, фото, дата рождения) и удаление — с подтверждением, каскадом всех его данных
- [ ] Пресеты при создании питомца: прививки — 12 месяцев, паразиты — 3 месяца, груминг — 2 месяца; пользователь может править и удалять
- [ ] Перзагрузка страницы сохраняет всё
