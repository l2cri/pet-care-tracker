# 03: Хранилище и JSON-бэкап

**What to build:** Всё состояние приложения переживает перезагрузку и выгружается/загружается JSON-файлом с `formatVersion`. localStorage спрятан за интерфейсом репозитория, чтобы потом заменить на что угодно, не трогая ядро и UI.

**Blocked by:** 02 (Доменное ядро — нужны типы модели).

**Status:** done

- [x] Интерфейс репозитория (загрузить / сохранить / стереть) + in-memory реализация для тестов
- [x] localStorage-реализация — тонкая обёртка; при первом запуске возвращается пустое состояние
- [x] Экспорт всего состояния в JSON с полем `formatVersion`; импорт восстанавливает данные без потерь (round-trip тест)
- [x] Битый или чужой JSON при импорте даёт понятную ошибку и не портит текущее состояние
- [x] Автосохранение hook-интеграцией: любой тестовый прогон сохраняет состояние через in-memory репозиторий
