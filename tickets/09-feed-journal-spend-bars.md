## Замечания ревью

Ревью-сессия (Standards + Spec) против merge-base с master: P1/P2 нет после правки,
все 5 критериев подтверждены. Исправлено по итогам: геометрия столбиков
(автоскейл, вырожденные случаи, клампинг) вынесена из SpendBars в домен —
`barsGeometry(months, layout)` в `src/domain/spend.ts` с 5 тестами (ADR-0005).

Не блокируют мерж, кандидаты на будущую уборку:

- **P3.** Дублирование CSS: `.minorButton`, `.removeButton`, пустое состояние и
  `.fab` скопированы из PetCard.module.css (~90 строк). Общие стили кнопок/FAB —
  кандидат в общий модуль (прецедент: form.module.css); мешает правке из двух
  веток (08 правит PetCard).
- **P4.** Компаратор сортировки по дате дублирует DoneEventsSheet — кандидат в
  общий хелпер `byDateDesc`.
- **P4.** `role="img"` у SpendBars даёт скринридеру только сводную подпись окна;
  суммы отдельных месяцев недоступны (смягчено журналом с ценами под графиком).
- **P4.** `border-radius: 999px` у бейджа вердикта — единственный радиус мимо
  токенов (s/m/l); «пилюля» не выражается фиксированным токеном.
- **P4.** Правка цены открывается с точкой (`String(890.5)`) при общем соглашении
  запятой; валидация точку принимает, косметика.
- **P4.** `monthShortLabel` показывает год только на январе: окно июль–декабрь
  без года нигде — край, допустимо.
